# My Ideas for Spandan

Spandan Project — Full Wrap-Up
What is Spandan?
Spandan is a project aimed at improving student engagement during live lectures/stand-ups by generating real-time polls based on what the teacher is saying, and tracking student responses.

Core Concept:

Teacher starts a room, sets parameters, turns on a mic in the Spandan app, and the system auto-generates questions (True/False, MCQ, MSQ) at set or random intervals

Teacher does a quick review before pushing questions to students

Integrates with Spurti points for engagement tracking

Key Discussion Points & Participant Inputs:

Random vs. fixed poll timing: Majority agreed polls should be random to prevent gaming; fixed timing allows students to show up only for polls

Separate app vs. plugin:

Separate in-house app gives full control and avoids third-party restrictions

Plugin approach (for Zoom/Meet) was also suggested for scalability, but approval/restriction issues noted

Rohit Sir favored open-source so any coaching institute can clone and use it

YouTube Live integration: Proposed to run live streams inside Spandan itself using a room code, so only intended students join

AI backend: Suggested to auto-generate notes and questions from transcription using an AI engine

Question types: Current true/false format seen as insufficient; richer question types needed

Planned Next Steps:

Explore open-source release for broader adoption
